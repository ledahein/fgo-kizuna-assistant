# FGO 羁绊加成礼装覆盖助手

给 FGO 配队用的小工具：给定队伍，自动算出每张羁绊加成礼装的覆盖人数。

## 在线使用

**https://ledahein.github.io/fgo-kizuna-assistant/**

手机打开后「添加到主屏幕」，之后像 App 一样全屏使用；数据内置，断网可用。

## 两个标签页

### 队伍覆盖

输入从者名 → 点选候选 → 选战斗形象阶段 → 自动算出 12 张羁绊礼装各覆盖几位。

- 支持名字、别名、`名字+职阶` 模糊搜索（如 `玉藻亚里亚rider`、`弗朗`）
- 多形态从者（普勒拉蒂、杰基尔、苍崎青子）会弹出形态选择
- 结果按覆盖数降序，徽章 4/2/1/0 配色区分

### 反向查询

选一张礼装 + 筛选职阶、星级（均可多选）→ 列出满足该礼装条件的从者。

礼装按条件显示（如「星or恶 20%绊」「混沌+七骑士 20%绊」），不用记礼装名。

## 数据

- **471 位从者**（已排除 12 位无法召唤的 NPC）
- **12 张达芬奇工坊羁绊加成礼装**（+4% / 最大解放 +20%）
- 来源：[Mooncell 英灵图鉴](https://fgo.wiki/)
- 点「检查更新」可自动拉取新增从者与新礼装

## 判定口径

- 一张礼装装备后，**全队满足条件者都获得加成**
- 每张礼装只有一张，不可重复装备
- 多数礼装命中任一条件即可；**「混沌+七骑士」「秩序+女性」「秩序+善」需要两条同时满足**
- 「拥有星之力的从者」按**副属性「星」**判定，不是特性
- 七骑士 = Saber / Archer / Lancer / Rider / Caster / Assassin / Berserker
